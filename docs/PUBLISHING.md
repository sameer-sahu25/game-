# Publishing (Phase 12)

Do **not** claim the experience is live until it is uploaded from your Roblox account.

1. Finish `docs/TESTING.md` on a private place.
2. Create the experience in Creator Dashboard.
3. Set name **BATTLE LEGENDS**, description from the PRD tagline and loop.
4. Upload icon/thumbnail (original art; this repo does not ship a published image asset).
5. Enable DataStore API for the published universe.
6. Confirm all animation/audio IDs are owned by the same creator or group.
7. Age rating / guidelines: stylized combat, no realistic gore.
8. Private testers first, then public.

Post-release: watch DataStore errors, combat remote abuse logs (add `warn` if needed), and part-count in arenas if you add meshes.
